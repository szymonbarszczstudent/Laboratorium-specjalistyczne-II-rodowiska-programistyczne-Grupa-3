System blogowy
Ma on za zadanie umożliwić dodawanie wpisów, obrazki, komentarze, treści, tagi i polubienia przez użytkowników.
System będzie miał 4 typy użytkowników: administratora, użytkownika zarejestrowanego, użytkownika niezarejestrowanego i  autora.
Autor będzie mógł zapisać artykuł jako wersję roboczą, opublikować go od razu lub zaplanować jego publikację na określony termin.
System zakłada możliwość wyszukiwania treści po kategoriach, konkretnych autorach lub w jakimś przedziale czasowym.
